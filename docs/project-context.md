## 已实现的功能

### 1. 拼图关卡（index.html）
- 客厅 → 桌面 → 3×3 拼图，灰度碎片拖拽归位，归位恢复彩色
- 完成 3s 彩色展示 → 2s 褪色动画
- 已修复：DPR 适配、横屏提示、拖拽手感、黑边问题

### 2. 签字→白板关卡（sign_to_whiteboard.html）
**流程：**
1. 加载签字底板图（飞书文档面板 2）
2. 静置 2.5s → 自动从右下角"签字处"区域放大
3. 放大至裁剪块填满屏幕 → 替换为纸张底板
4. 玩家在纸上手写"向阳"二字

**笔画变形规则：**
- 横 ↔ 竖（互转）
- 撇 ↔ 捺（互转）
- 点、折 → 不变

**匹配逻辑：**
- 画布分左右两区（左=向，右=阳）
- 左区需要横+竖+折混合，右区需要横+竖混合
- 阈值 80 分，笔画少于 6 拒绝

**交互细节：**
- 右上角 10s 倒计时
- 超时提示：阿尔兹海默症语境——"有些记忆刻在手上，连笔写下去，疾病抢不走"
- 清除按钮（提交旁）
- 提交按钮（右下）

## 关键技术决策

| 决策 | 内容 |
|------|------|
| 纯客户端匹配 | 平台禁网络请求，OCR 走不通，用笔画特征模糊匹配 |
| 连笔绕过规则 | 多方向变化的笔划被分类为`fold`(折)，折不变形 |
| 签字图来源 | 飞书文档 `TWQjwGO2AiZ2urkxL0ucZF7Hn3f`，面板2 |
| 转场方式 | 裁剪签字区矩形块→放大至填满屏幕 |
| 适配方式 | 1280×720 逻辑分辨率，cover-fit 缩放，DPR 适配 |
| 文件分发 | 原模块化 `src/` 用于本地开发；飞书妙搭部署时合并为单文件 |

## 美术风格

- 暖旧纸张色调（#fcf5e6 → #e8d4a0）
- 纸纹噪点、边缘旧化、淡污渍
- 签字底板与纸张底板视觉统一
- 签字区在表单右下（canvas 坐标约 x=550, y=840, w=750, h=200）
