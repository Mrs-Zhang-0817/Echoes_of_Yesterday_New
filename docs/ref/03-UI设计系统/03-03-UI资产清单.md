## 8. UI 文件（71 个）

包括 HTML 页面、JS 模块、CSS 样式、JSON 配置、HTML 页面等完整列表（详见 PACKAGE_CONTENTS.txt 或 UI_ASSET_MANIFEST.json 的 `uiFiles` 字段）。核心文件构成：

- **入口页面：** `main-menu.html`、`memory-report-artwork.html`、`memory-report.html`、`chapter-select.html`
- **UI 核心层：** `src/ui/core/`（UIManager.js / UIComponent.js / UILayer.js / AssetRegistry.js / FontManager.js / TextStyleManager.js / UIAssetManager.js）
- **UI 组件：** `src/ui/components/`（MemoryPanel / MemoryClarity / MemoryItem / PhotoFrame / Stamp / DateStamp 等 13 个组件）
- **UI 屏幕：** `src/ui/screens/MemoryReportScreen.js`
- **UI 状态：** `src/ui/state/MemoryRestoreStateManager.js`
- **UI 材质：** `src/ui/materials/PaperMaterial.js`、`PhotoMaterial.js`、`TextMaterialLayer.js`
- **UI 动画：** `src/ui/animations/MemoryRestorationSequence.js`
- **UI 样式：** `src/ui/styles/`（memory_report.css、memory_restoration.css、ui_constants.js、ui_materials.css）
- **UI 排版：** `src/ui/typography/typography.css`、`TypographyConfig.js`
- **旧版数据：** `src/data/`（chapter_01.json、chapter_test.json）
- **旧版场景：** `src/scenes/`（puzzleLayout.js、Scene_Desk.js、Scene_Puzzle.js、Scene_Room.js、sceneUtils.js）
- **核心引擎：** `src/core/Game.js`、`InputManager.js`、`Loader.js`、`SceneManager.js`
- **配置：** `src/ui/memory-report-config.json`、`src/ui/ui-config.js`、`src/memory-report-artwork-config.js`
- **文档：** `docs/` 目录下各文档、清单、验证报告
