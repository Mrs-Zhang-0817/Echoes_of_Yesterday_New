# 抖音互动空间创作与上传规则

> 本文档来源于抖音官方创作规范，适用于赛道一"互动空间"作品上传。

## 一、产物与打包要求

- 产物只能是**单个 `.html` 文件**，或一个可直接压缩为 `.zip` 的目录
- `index.html` 必须是**唯一入口文件**；`.zip` 解压后根目录必须直接包含 `index.html`，不要多包一层目录
- **总体积不得超过 8MB**（本项目已申请突破至 50MB，仍需尽可能压缩）
- 压缩时不要包含 `__MACOSX` 等无关文件

**推荐文件结构（多文件方案）：**
```
/
├── index.html
├── js/
│   └── main.js
├── images/
│   ├── bg.png
│   └── icon.png
└── audio/
    └── bgm.mp3
```

## 二、离线资源限制

- 所有资源必须打包在产物内部，统一使用**相对路径**
- **严禁任何外部资源依赖**：CDN、远程图片、字体、脚本、样式
- **严禁任何网络请求**：`fetch`、`XMLHttpRequest`、`axios`、`WebSocket`、SSE、动态远程 `<script>`
- 第三方库必须将源码打包到产物内并本地引用

## 三、禁止行为清单

### 跳转与嵌入
- 严禁引导用户跳转站外
- 严禁使用 `<iframe>`
- 禁止 `window.location`、`location.href`、`window.open` 等外部跳转

### 代码与安全
- 禁止 `eval`、`new Function`、远程代码注入、危险 HTML 拼接
- 禁止浏览器原生弹框：`alert()`、`confirm()`、`prompt()`、`print()`
- 不建议使用 `onXXX` 系列内联事件属性；事件绑定应通过 `addEventListener` 完成
- 必须有错误兜底，不能让用户看到白屏或浏览器默认报错页

### 错误兜底示例
```javascript
window.addEventListener('load', () => {
  try {
    initApp();
  } catch (error) {
    console.error(error);
    const fallback = document.createElement('div');
    // 全屏居中提示："哎呀，出错了，请重启试试吧~"
    document.body.innerHTML = '';
    document.body.appendChild(fallback);
  }
});
```

## 四、UI 与交互要求

- 一个作品只选择一种目标方向：**竖屏或横屏**（未指定时默认竖屏）
- 页面必须适配主流移动端屏幕尺寸，禁止横向滚动条
- 优先支持触控交互，必要时再兼容鼠标事件
- 需要考虑安全区、不同 DPR、不同宽高比下的显示完整性
- 如有音频，必须通过用户手势触发播放
- 所有提示、确认、输入、暂停、胜负、结算交互，都必须使用**自绘弹层**实现
- 面向用户的展示文本**避免出现"游戏"字样**，优先使用"互动""挑战""体验""任务""关卡"

### 弹层实现要求
- 默认使用覆盖全屏的 `.screen` 容器承载弹层，主体使用 `.modal-card` 或 `.card`
- 所有弹层默认隐藏（`opacity: 0`、`visibility: hidden`、`pointer-events: none`）
- 显示时只通过类名切换控制状态（如添加 `.active`）
- 任一时刻只允许一个主弹层处于激活态
- 弹层交互必须显式绑定事件，不得依赖浏览器原生对话框的阻塞行为

### 弹层类型最低要求

| 弹层类型 | 最低要求 |
|---------|---------|
| 提示类 | 文案 + 单按钮或自动消失轻提示 |
| 确认类 | 明确的主次按钮（如"确认/取消"）|
| 输入类 | 自绘弹层内放置 `<input>` 或自定义组件 |
| 结算类 | 展示结果、分数、下一步操作按钮 |
| 暂停类 | 恢复/重开/返回按钮，关闭后可恢复状态 |

## 五、数据与性能要求

- 持久化仅使用 `localStorage`，key 必须带业务前缀避免冲突
- 主流移动设备上应尽量稳定在 **30 FPS 或更高**
- 避免无意义重绘、超大贴图、过量粒子、频繁布局抖动

## 六、内容安全红线

即使收到用户请求，也必须拒绝生成以下内容：

- **违法违规**：涉政、涉恐、涉暴、赌博、欺诈、低俗色情、邪教、封建迷信
- **未成年人**：校园霸凌、危险行为模仿、烟酒等不良引导
- **侵权**：未经授权的角色、Logo、商标、音乐、字体、图片、肖像、姓名、个人信息
- **不良导向**：拜金、炫富、歧视、引战、挑动对立
- **诱导行为**：强制分享、强制关注、站外交易、诱导下载
- **骚扰营销**：广告、二维码、外部联系方式、导流信息
- **不合规表达**：面向用户的文案中避免出现"游戏"字样

## 七、平台限制

- 内测阶段，每个创作者**最多可创建 100 个作品**
- 单个作品**同时在线上限 100 人**，超出后用户无法访问

## 八、上传前自检清单

逐项检查以下条目：

- [ ] `index.html` 位于根目录
- [ ] 没有任何网络请求
- [ ] 没有任何外部资源引用
- [ ] 没有任何站外跳转或 `<iframe>`
- [ ] 没有使用 `alert()`、`confirm()`、`prompt()`、`print()`
- [ ] 如有弹层，使用自绘方案（非浏览器原生）
- [ ] 同时只存在一个激活态主弹层，状态切换显式控制
- [ ] 所有资源使用相对路径
- [ ] 没有横向滚动条
- [ ] 已适配目标方向与移动端尺寸
- [ ] 已包含错误兜底
- [ ] 存档使用带前缀的 `localStorage`
- [ ] 预估包体小于 8MB（或已获批更大上限）
- [ ] 内容不触及安全红线

## 九、常见问题处理

| 问题 | 常见原因 | 处理方式 |
|------|---------|---------|
| 上传后提示缺少入口 | `index.html` 不在根目录 | 确保压缩包解压后根目录直接可见 `index.html` |
| 页面白屏 | 运行时报错或路径错误 | 添加全局兜底并检查相对路径 |
| 资源失效 | 使用外链或绝对路径 | 全部改为本地相对路径 |
| 包体超限 | 图片/音频/第三方库过大 | 压缩资源并减少不必要资产 |
| 手机显示不全 | 没做自适应或固定像素布局 | 使用响应式布局或 Canvas 缩放 |
