# 05-05 章节数据配置

## 概述

`src/data/chapters.json` 是项目共 10 章的元数据配置文件，在启动时由 ChapterManager 加载，驱动章节注册、导航和记忆进度系统。JSON 格式，长度为 10 的数组。

---

## 章节元数据表

| order | id | title | memoryUnlock |
|-------|-----|-------|-------------|
| 1 | `ch01_intro` | 序曲·镜前 | 5 |
| 2 | `ch02_puzzle` | 接女儿放学 | 15 |
| 3 | `ch03_maze` | 迷途 | 22 |
| 4 | `ch04_police` | 警局 | 30 |
| 5 | `ch05_door` | 归家迷途 | 40 |
| 6 | `ch06_table` | 餐桌上的博弈 | 52 |
| 7 | `ch07_night` | 惊悚夜醒 | 60 |
| 8 | `ch08_sign` | 走廊的镜子 | 72 |
| 9 | `ch09_chime` | 风铃 | 85 |
| 10 | `ch10_report` | 认出 | 100 |

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 章节 ID，对应 `src/chapters/chXX_*.js` 文件名和 ChapterManager 注册 key |
| `title` | string | 章节中文标题，显示在 UI 和弹层中 |
| `memoryUnlock` | number | 完成本章后累计获得的记忆值（百分比），范围 5~100 |
| `order` | number | 章节顺序编号 1~10，决定导航顺序 |

---

## 记忆增长曲线分析

各章节完成后的累计记忆值（memoryUnlock）呈现**非线性递增**特征：

```
ch01     5 ┤█
ch02    15 ┤███
ch03    22 ┤████
ch04    30 ┤██████
ch05    40 ┤████████
ch06    52 ┤██████████
ch07    60 ┤████████████
ch08    72 ┤██████████████
ch09    85 ┤█████████████████
ch10   100 ┤████████████████████
```

### 增长趋势

| 段 | 章 | 区间 | 增量 | 特征 |
|----|-----|------|------|------|
| 开篇 | ch01~ch03 | 5→22 | +5,+10,+7 | 起步平缓，节奏轻 |
| 中段 | ch04~ch06 | 30→52 | +8,+10,+12 | 递增加快 |
| 高潮 | ch07~ch09 | 60→85 | +8,+12,+13 | 高增量段 |
| 终章 | ch10 | 100 | +15 | 最终冲刺，完整记忆 |

### 设计意图

- **前 3 章（22% 记忆）**：玩家学习操作阶段，回报较低，避免信息过载
- **中 4 章（30→60%）**：认知曲线渐陡，体验逐步深入
- **后 3 章（60→100%）**：高潮段，记忆值大幅跃升，驱动玩家完成全章
- **累计 100% 收官**：终章 +15 完成"认出"主题，记忆完整复原

## 使用方式

```javascript
// ChapterManager 启动时加载
const chapters = await fetch('./src/data/chapters.json').then(r => r.json());
// 或作为 ESM 模块导入（开发期）
import chapters from './data/chapters.json';

// 遍历注册
chapters.sort((a, b) => a.order - b.order).forEach(ch => {
  chapterManager.register(ch.id, ChapterClass);
});

// 读取当前进度对应的章节
const currentChapter = chapters.find(ch => ch.order === currentChapterNum);
// currentChapter.memoryUnlock → 用于进度条和记忆报告
```
