## 三、接入预案

当前 `src/chapters/` 没有 `ch04_police` 模块，这 8 张图目前没有可引用的代码位置。接入时需完成：

1. 从 `assets-source/ch4_police/` 复制需要用的图到 `assets/images/`
2. **压缩**：单张 2.4-2.8MB，建议转 JPEG Q80，目标 <300KB/张（抖音互动空间 zip 限 8MB）
3. 在 `src/main_new.js` 的 `manifest` 注册（如 `policeBg`、`policeInterior`、`bracelet` 等）
4. 实现/补全 `src/chapters/ch04_police.js`，在对应 phase 用 drawImage 引用
