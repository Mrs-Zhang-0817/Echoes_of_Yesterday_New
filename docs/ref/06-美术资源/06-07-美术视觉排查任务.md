## 六、已知视觉问题

### P0 - 图放错（暂无记录）

如果发现图完全不是该场景内容，需立即替换。

### P1 - Ch7 门锁过小过高

- 问题：原图 971x1619，渲染尺寸仅 60x100（缩放比 6%）
- 在极暗背景（88% 遮罩）下几乎不可见
- 建议：增大渲染尺寸至 90x150 或增加光晕辅助视觉引导

### P1 - Ch5 向日葵贴纸过小

- 问题：原图 1254x1254，渲染尺寸仅 68x68
- 在电梯面板背景下难以注意到
