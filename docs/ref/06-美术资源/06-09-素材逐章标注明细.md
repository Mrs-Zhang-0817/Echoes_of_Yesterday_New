# 素材逐章标注明细

> 本文件对 `assets/images/` 下所有 **运行时图片**（即 `assetManifest.js` 中引用的资源 + 磁盘上存在的相关图片）做逐张标注。
>
> 来源判定规则：以 `CH2_` / `CH3_` / `CH5_` / `CH7_` / `CH8_` / `CH9_` 大写字头开头的原始文件来自 `art-library/generated/`（AI生成精调素材）。
> 其余来源可能为旧仓库迁入或项目早期自建。
>
> 使用方式说明：`drawImageCover` = 拉伸铺满画布（保持比例居中裁剪）；`drawImage` = 指定坐标/尺寸绘制。
>
> 文件大小以实际磁盘文件为准。标注 "需人工确认" 表示从代码无法明确推断。
