# 比赛备忘录

## 比赛实测发现的问题

### 拼图拖拽手感差

- 电脑端用触控板去拖拼图的手感比较糟糕，需要修复和调整
- 吸附手感要求：自动吸附的优先级高于人手拖动，尽可能敏感度高，降低玩家的门槛
- 待后期调整吸附手感

### 弹窗速度与 UI 问题

- **章节完成弹窗**：弹窗跳的速度太快，UI 有问题
  - 背景为浅黄色，文字"记忆恢复了一些......但那抹色彩，终究会慢慢褪去......"
  - 底部有棕色"继续下一章节"按钮
- **记忆解锁弹窗**：
  - 黑色背景，浅棕色弹窗
  - 白色文字"一碗热面，唤醒沉睡的味觉"
  - 显示"记忆解锁 45%"
  - 底部有棕色"继续下一章节"按钮

### 迷宫交互优化

- 地图需要优化交互，让起点不断往前推进
