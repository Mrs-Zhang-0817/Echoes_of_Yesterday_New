## 2. 启动说明

在包目录启动任意静态 HTTP 服务：

```powershell
python -m http.server 8080
```

然后打开：
- `http://localhost:8080/main-menu.html` — 主界面
- `http://localhost:8080/chapter-select.html` — 章节选择页
- `http://localhost:8080/memory-report-artwork.html?chapter=chapter_01` — 记忆恢复报告

**不要直接双击 HTML。** Memory Report 使用 fetch 读取 `src/ui/memory-report-config.json`，浏览器的 file:// 安全策略会阻止该请求。
