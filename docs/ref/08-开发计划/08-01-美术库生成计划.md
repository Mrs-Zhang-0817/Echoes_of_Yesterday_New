# 美术库生成计划

## 目标

在不改动游戏代码或现有运行路径的前提下，建立可追溯美术库，并生成台账 G01–G26 的 26 张缺失素材。

- **可追溯**：现有运行素材与历史来源只做归档副本，保持 `assets/images/` 和章节代码不变
- **缺失补充**：新素材按章节落在 `generated/chXX/`
- **质量要求**：连续帧由同一生成任务顺序产出，透明互动件以绿幕图生成、去背和 alpha 验证后才归档

## 目录规划

```
assets/art-library/
├── existing-runtime/       # assets/images/ 的完整副本
├── feishu-raw/            # 飞书下载的原始素材
├── legacy-source/         # assets-source/ 的历史素材
├── generated/
│   ├── ch02/              # G01–G09
│   ├── ch03/              # G10–G18
│   ├── ch05/              # G19
│   ├── ch07/              # G20–G23
│   ├── ch08/              # G24–G25
│   └── ch09/              # G26
└── README.md              # 归档规则与验收记录
```

## 5 个任务分解

### Task 1: 建立可追溯美术库（已完成）

- 创建分章生成目录与来源归档目录（`mkdir -p` 8 个目录）
- 复制已有美术来源：`cp -pR assets/images` → `existing-runtime/`、`.tmp_feishu_imgs/` → `feishu-raw/`、`assets-source/` → `legacy-source/`
- 核验归档完整性（文件数一致检查）

### Task 2: 生成 Ch2 叙事资产 G01–G09（已完成）

- 4 个透明互动件：门框（CH2_Door_Frame）、打开糖盒（CH2_Tinbox_Open）、钥匙（CH2_Key_Inside）、糖果（CH2_Candy_Inside）
- 5 帧人物连续闪回（CH2_Flashback_01~05.jpg）
- 约束：父亲始终浅灰长袖衬衫+深蓝牛仔裤；女儿白色校服裙+双马尾+红书包；机位不变

### Task 3: 生成 Ch3 城市资产 G10–G18（已完成）

- 3 个静态背景：老社区（CH3_BG_OldCommunity）、城市街道（CH3_BG_CityStreet）、校门（CH3_BG_SchoolGate）
- 4 帧连续城市上摇画面（CH3_CityUp_01~04.jpg）
- 2 个透明 NPC：路人（CH3_NPC_Passerby）、红围巾女孩（CH3_RedScarf_Girl）

### Task 5: 完整性与风格验收（已完成）

- 更新 README.md：26 项交付清单 + 来源与验收结果

## 禁止改动清单

以下内容在美术库建设中**不得改动**：

- `src/` 目录下的任何代码
- `build_out/` 构建产物
- `index.html` 入口页面
- 现有 `manifest.json` 等配置文件
- `assets/images/` 中的运行素材（不做移动或覆盖，仅复制归档）
