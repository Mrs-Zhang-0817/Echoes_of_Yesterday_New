# Ch4 签字迁移、Ch7 弹幕与 Ch8 微笑实现计划

## 目标

将签字还原放入 Ch4，并让 Ch7 的可点击弹幕与 Ch8 的摄像头微笑/挥手回退在现有 Canvas 游戏中完整可玩。

## 架构原则

- 签字、弹幕和微笑检测拆为三个无关卡存档职责的互动模块
- 章节只负责状态流转、文案和完成后的进度写入
- 摄像头模块以隐藏视频元素作为 face-api 输入，所有权限失败都落到 Ch8 的挥手路径
- 运行入口仍是 `index.html` 的单 Canvas；触摸和鼠标都通过 `InputManager`

## 5 个任务分解

### Task 1: 提取并放宽可复用签字拼图（SignaturePuzzle）

- 创建 `src/interactions/SignaturePuzzle.js`
- API：`new SignaturePuzzle({ onComplete })`，暴露 `handleDown/HandleMove/handleUp/update/render/completed/attempts`
- 判定条件：
  - "向阳"笔画特征：6 笔以上，左右半区各含至少 1 横 + 1 竖笔画
  - 旧阈值 PASS_SCORE=80 废除
  - **第 3 次提交必然通关**（`attempts >= 3` 兜底）
- 嵌入 Ch4：在 `ringing` 和 `form` 状态之间插入 `signature` 状态
- 保持现有 `markChapterComplete(4, 30)` 不变

### Task 2: 添加 Ch7 可点击弹幕气泡场（DanmakuBubbleField）

- 创建 `src/interactions/DanmakuBubbleField.js`
- API：`new DanmakuBubbleField({ messages, targetX, targetY })`，暴露 `update/hit/render/start/collected/isReady`
- 技术参数：
  - 最多 **5 个气泡并发**
  - 生成间隔 1.2~2.2 秒
  - 20 秒超时兜底（超时后自动进入门锁搜索）
  - 点击气泡 → 飞向胸口（targetX, targetY）→ 到达后计入 collected
- 嵌入 Ch7：在 `narrative` 后增加 `comfort` 阶段
  - 渲染现有卧室 + 低血红色暗角作为气泡背景
  - `isReady` 时或 20 秒超时 → 过渡到门锁搜索

### Task 3: 添加本地微笑检测器（SmileDetector）

- 创建 `src/interactions/SmileDetector.js`
- API：`new SmileDetector({ faceapi, mediaDevices, now })`，暴露 `start/sample/stop/status/happyHeldSeconds`
- 技术参数：
  - **happy ≥ 0.6** 连续保持 **1.5 秒** 触发 smiling 状态
  - 采样间隔 0.2 秒
  - `sample()` 返回 `{ state: 'ready'|'smiling'|'failed', happy: number }`
- 加载 face-api 模型（6 个文件）：
  - `face-api.min.js`
  - `face_expression_model-shard1`
  - `face_expression_model-weights_manifest.json`
  - `tiny_face_detector_model-shard1/2`
  - `tiny_face_detector_model-weights_manifest.json`
- 不拷贝：`server.cjs`、`cert.pem`、`key.pem`
- `start()` 请求 `{ facingMode: 'user' }`；`stop()` 停止所有 track，清空 `video.srcObject`

### Task 4: 替换 Ch8 为镜中微笑 + 挥手回退

- Ch8 状态序：`mirror → camera → wave → reveal → complete`
- 渲染走廊/镜子资产 + 陌生人 + 裂纹叠加层
- 摄像头成功时：将镜像视频绘制到镜面区域 → 每 0.2s 取样 → 微笑触发 reveal
- 摄像头失败/拒绝/8 秒未就绪 → 显示挥手指令
- **挥手回退判定**：大幅弧形路径（左→右→左，约 900px 跨幅）
- `reveal` 阶段：裂纹淡出 + 陌生人交叉淡入 `ch8_mirror_smile`（老人微笑图）
- 完成后调用 `markChapterComplete(8, 72)`
- 更新 `chapters.json` 的 Ch8 标题/进度配置

### Task 5: 全验证 + 隔离交付

- 单元测试套件全通过
- Playwright 浏览器流程回归（不依赖真实摄像头）
- 构建通过
- 确认远程仓库为 `Echoes_of_Yesterday_New.git`
