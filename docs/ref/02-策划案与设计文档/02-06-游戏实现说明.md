# 游戏实现说明

> 本文档精确记录「昨日重现」（Echoes of Yesterday）的当前版本实现现状。性质为 As-Built Description——非需求文档、非代码改动。生成方式：逐文件精读 `src/`、manifest、`data/chapters.json` 与 `assets/images/`，本地浏览器启动截图核验 + 自动化测试交叉确认。

---

## 一句话概览

一款 **1280×720 横屏 Canvas 2D** 叙事互动游戏，以**阿尔茨海默症父亲的第一人称视角**展开，共 **10 章**。玩家通过点击/拖拽/手写等轻交互，逐章"唤醒"记忆。全局"记忆恢复进度"主线，终章以"记忆恢复档案"报告页收尾，可一键重新开始。

## 技术架构

### 运行形态

- **开发态**：`src/` 下 ES Modules 模块化（每章一个 class，核心框架在 `src/core/`）
- **上线态**：`build.cjs` 将模块拼接为单文件 `index.html`
- **入口**：`index.html` → `<script type="module" src="src/main_new.js">`

### 主循环与帧率

- `Game.js` 用 `requestAnimationFrame` 驱动；每帧 `dt = min((timestamp-lastTime)/1000, 0.1)`——**单帧上限 100ms**
- 渲染顺序：章节 render → 转场 renderTransition → 全局 Overlay

### 章节状态机与转场

- `ChapterManager.js` 驱动 onEnter/update/render/handleDown 生命周期
- **转场**：0.3s 黑屏淡入淡出（`rgba(0,0,0,alpha)` 铺满）
- 当 `chapter.isComplete` 为真时：弹出记忆恢复报告 Overlay，phase 置 `blocked`

### 叙事活动层（解耦）

- 所有"非互动的叙事呈现"（闪回报告、闪回活动、终章蒙太奇）抽成 `src/narrative/` 下的独立模块
- `FlashbackActivity` / `MontageActivity`
- 维持 `start/update/render/isFinished` 契约即可替换

### 全局叙事弹层 Overlay

- 遮罩 `rgba(0,0,0,0.6)`；卡片 **420×280** 居中（圆角16）
- 排他性：同一时刻只允许一个弹层
- 完成类弹层由 ArtworkMemoryReport 绘制（含底图 + 进度条 + "继续下一章节"按钮）

### 进度存储

- localStorage key **`ye_v1_progress`**
- `markChapterComplete(num, memory)`：取 `max(旧值, memory)` 写入
- 进度恢复：`resumeNum = min(saved.chapter + 1, 10)`

### 调试接口

- `D`：快照；`F`：强制完成；`1-0`：跳转到对应章节
- `window.__debug__`：inspect/state/screenshotMeta/forceComplete/switchTo

## 逐章详述（Ch1-Ch10）

### Ch1 序曲·镜前（ch01_intro.js）

- **phase**：idle → shattering → complete
- **镜面**：椭圆 MIRROR_CX=640, CY=340, RX=250, RY=325；呼吸光周期 **3s**
- **触发**：点击镜热区 **或** 累计点击 **3 次** → startShattering
- **碎裂**：30个碎片粒子（初速80-300，存活1.5-2.5s）+ 5-7条裂纹；vibrate(30)
- **节奏**：碎裂 → 0.3s 裂纹渐显 → 0.5s 淡入 → **2s 后** complete → markChapterComplete(1,5)
- **弹层**：标题"回忆的碎片" / 正文"镜中的自己……是谁？"
- **美术**：仅 `mainMenuBg` + 程序化压暗；卧室/镜子/收音机套件全未用

### Ch2 接女儿放学（ch02_puzzle.js）

- **phase**：playing → completeHold → fadeMemory → complete
- **拼图**：面板 x:370,y:120,w:540,h:405，pieceScale 0.7，snapRadius 50（触摸96）
- **灰阶预生成**：离屏 Canvas 预生成灰度（兼容 iOS Safari <18）
- **节奏**：拼合完成 → completeHold **3s** → fadeMemory **2s** → markChapterComplete(2,15)
- **闪回帧**：ch2_flashback_01~05，frame=min(5, floor(phaseTime*1.7)+1)
- **美术**：puzzle(scene_puzzle.jpg) + 闪回帧5张；铁盒/钥匙/糖果/照片未用

### Ch3 迷途（ch03_maze.js + ch03_mazeLayout.js）

- **phase**：idle → drawing → success/wrong → complete
- **迷宫**：11正确节点 + 8误导 + 6死胡同，nodeRadius 50
- **错误**：0.8s 重置 + vibrate(30)
- **成功**：1.8s → markChapterComplete(3,22)；城市帧 ch3_cityup_01~04
- **美术**：仅 ch3_map_phone + 城市帧；老社区/街道/校门/NPC/红领巾全未用

### Ch4 警局（ch04_police.js）

- **phase**：phone → ringing → form → bracelet → complete
- **背景**：ch4_police_01 + 压暗（8张只用第1张）；背景是旧城改造街景而非警局
- **电话呼吸**：脉冲 0.1+0.3*(0.5+0.5*sin(totalTime*2π/1.5))
- **节奏**：点击电话 → ringing 3次脉冲 (~0.3s间隔) → form (~1.05s) → 手环热区(120,560)半径40 → bracelet 2s → markChapterComplete(4,30)
- **登记单线索**：红色大字"【重点】XX小区 5栋 503"

### Ch5 归家迷途（ch05_door.js）

- **phase**：narrative → gating1 → gating1_celebrate → gating2 → gating2_elevating → complete
- **⚠️ 关键问题**：gating1（声相定位）叙事后未进入流程，直接跳到 gating2
- **gating2 电梯**：6个扭曲按钮，correctIndex=5（向日葵贴纸）
- **成功**：2.5s → markChapterComplete(5,40)
- **⚠️ 弹层写"记忆解锁35%"但写入 memory=40**
- **⚠️ Ch4登记单"503"未被本章读取**，正确答案是向日葵贴纸6

### Ch6 餐桌博弈（ch06_table.js + tableLayout.js）

- **phase**：narrative → gating1 → gating1_done → gating2 → gating2_celebrate → complete
- **narrative**：4s 或点击(>1.5s) → gating1
- **gating1 触觉**：停留碗中 comfortProgress，comfortTime=3.0s，衰减0.3/s；蒸汽12粒子
- **gating2 气味**：收集70%且需3种气味，transformProgress 1.5s → 2s → markChapterComplete(6,52)
- **⚠️ 弹层写"记忆解锁45%"但写入 memory=52**

### Ch7 惊悚夜醒（ch07_night.js）

- **phase**：narrative → searching → found → complete
- **narrative**：5s 或点击(>1.0s) → searching
- **门锁**：lockX=640, lockY=500；80噪点；呼吸 alpha 0.04-0.08（周期3.5s）
- **超时兜底**：50s warmLight → 58s 月光滑 → 60s timeoutRevealed（之后任意点击开门）
- **found**：openProgress **1.0s** → markChapterComplete(7,60)

### Ch8 自我和解（ch08_sign.js）

- **phase**：sign → zoom → writing
- **sign**：2.5s 展示签名纸 + 走廊背景
- **zoom**：1.6s 缓动推近（easeInOutCubic）
- **writing**：笔画分类（dot/horizontal/vertical/fold/na/pie），畸变规则（横↔竖、撇↔捺）
- **PASS_SCORE=60**，需≥5笔或横扫手势；超时 TIMEOUT_SEC=10；MAX_ATTEMPTS=5
- **markChapterComplete(8,72)**

### Ch9 风铃（ch09_chime.js）

- **phase**（六态）：intro → colorRebuild → flashback → rhythmGame → resolve → complete
- **intro**：3s 自动或轻触跳过
- **colorRebuild**：4个音符拖拽归位，吸附 < 75px
- **flashback**：ch9_father_building_chime 闪回活动，perFrame 2.6s
- **rhythmGame**：4条轨道，速度230（慢速150），命中 ±90px；10个音符，连续3次漏击→ slowMode
- **resolve**：2.5s → markChapterComplete(9,85)

### Ch10 认出（ch10_report.js）

- **phase**（四态）：porridge → montage → reunion → finalReport
- **isComplete 永远返回 false**（自管终局）
- **porridge**：热粥热区(hitRadius 150) → montage
- **montage**：MontageActivity，4帧+4句字幕，perFrame 1.6s
- **reunion**：白色淡入定格，3.0s → finalReport
- **finalReport**：markChapterComplete(10,100)；10章列表+进度条+"重新开始"
