# demo 描述 · 互动设计

> 本文档是「昨日重现」项目最关键的互动设计文档。提取自飞书设计文档和本地 demo 描述，覆盖设计理念、交互系统架构、全十章互动详细设计、互动-病理对照总表、BGM 配置和乐曲变体。

---

## 一、设计理念

**项目名称**：昨日重现 / Echoes of Yesterday  
**项目类型**：以阿尔茨海默症为主题的叙事向 HTML5 移动端游戏  
**核心叙事**：玩家扮演一位罹患阿尔茨海默症的老人，通过互动玩法，在记忆日渐模糊的世界中努力找回与女儿"丫丫"之间的珍贵回忆。故事跨越 10 个章节，记忆解锁度 0%→100%。

**核心理念**：互动不是炫技，而是让玩家亲身体验阿尔茨海默症的症状——记忆错乱、空间迷失、物品失认、镜像失认、视觉词汇失认等。每个互动玩法对应一种病理表现。

---

## 二、互动系统架构

### 2.1 核心模式：叙事状态机 + 互动节点

```
叙事文本 → 互动节点 → 叙事文本 → 互动节点 → ... → 章节结算
```

每个章节是一个独立的状态机，通过 `this.phase` 变量管理流程。

### 2.2 7 种互动原语

| 原语 | 组件名 | 适用章节 | 说明 |
|------|--------|---------|------|
| 单次点击 | TapTarget | Ch1/2/5/7/8 | 点击物件触发事件 |
| 快速连点 | RapidTapZone | Ch1 | 限定时间内达到目标点击数 |
| 长按 | HoldGesture | Ch6 | 按住指定时长，进度填充+反馈 |
| 拖拽吸附 | DragSnap | Ch2/9 | 拖物品到目标位置 40px 内自动吸附 |
| 滑动连线 | SwipePath | Ch3/7 | 手指在屏幕上画线/连接路径 |
| 手写输入 | StrokeInput | Ch4 | 手写笔画识别，含笔画畸变干扰 |
| 陀螺仪/重力 | TiltSensor | Ch5/7/8 | 利用设备陀螺仪旋转视角 |

### 2.3 共享基础组件

| 组件 | 用途 |
|------|------|
| NarrativeTextBox | 叙事文本对话框（底部羊皮纸样式，逐字显现） |
| MemoryProgressBar | 记忆解锁度墨迹填充进度条 |
| VisualNoise | 视觉噪点/耳鸣覆盖层 |
| SceneTransition | 章节进入/退出翻页动画 |
| AnxietyVignette | 屏幕边缘红色焦虑半透明遮罩 |

## 三、全十章互动详细设计

### 第一章 · 儿时的回忆（0%→5%）

**病理展示**：失忆症——忘记自己已是老人

| 阶段 | 类型 | 内容 | 交互 |
|------|------|------|------|
| 1 | 叙事 | 清晨阳光、泥土青草香、环境描写 | — |
| 2 | **互动A** | 留声机播放《让我们荡起双桨》 | **单击**播放按钮 |
| 3 | 叙事 | 哼歌，想跑出去玩 | — |
| 4 | 叙事 | 阿妈喊"把衣服穿好再出去玩" | — |
| 5 | **互动B** | 衣服太大往下掉——扶正 | **快速连点**扶正衣服 |
| 6 | 叙事 | 照镜子吓一跳——镜中白发老人 | — |
| 7 | 叙事 | 喊阿妈没人应，低头看干瘪的手 | — |
| 8 | 过渡 | 视觉噪点、耳鸣、进入黑暗 | VisualNoise自动播放 |
| 9 | 结算 | 记忆解锁 5% | — |

**互动A 留声机按钮**：
- 老式留声机（唱片+唱臂+黄铜按钮），按钮暖金脉冲提示
- 点击后按钮沉入 3px，唱片旋转，音乐响起（叠加黑胶噼啪声）
- 状态：idle → pressed → playing

**互动B 快速连点扶衣**：
- 2 秒内 ≥6 次点击→成功；每次点击上提 12px，每 200ms 下滑 3px，最大下滑 80px
- 失败→衣服掉地→"再试试"；成功→焦虑消失

| 4 | **闪回** | 连续帧动图：合照→挥手→女儿进校 | 自动播放 5帧序列 |
| 5 | 叙事 | 恢复记忆——要去接女儿丫丫 | — |

| 7 | **互动C** | 发现铁糖盒——滑动锁扣打开 | **点击+滑动**解锁 |
| 8 | 叙事 | 拿糖出门→忘记拿钥匙 | — |
| 9 | 结算 | 记忆解锁 15% | — |

**互动A 拼图**：
- 程序从 CH2_Photo_Puzzle_Full.jpg 通过 Canvas 切成 2列×3行 6块
- 拖拽到正确位置 40px 内自动吸附，每拼好一块→局部恢复色彩
- 6块全部就位→触发闪回

**闪回帧序列**：
- 5张连续静态图，~400ms/帧
- 帧①父女校门口合照→②父亲抱女儿→③女儿挥手→④女儿跑向校门→⑤校门空镜
- 全部 sepia 老照片色调

**互动B 场景探索**：
- 底部返回按钮，选项"回到书桌看看"、"去门口看看"
- 到书桌→拼图+台历→台历变铁糖盒
- 到门口→钥匙挂空→便利贴模糊→提示回书桌

**互动C 铁糖盒**：
- 点击铁糖盒→打开动画，锁扣滑动解锁→钥匙🔑和糖🍬
