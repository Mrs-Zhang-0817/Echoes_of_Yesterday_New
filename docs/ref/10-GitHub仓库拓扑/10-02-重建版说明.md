# 重建版说明

## 项目概述

`Echoes_Of_Yesterday_Rebuilt/` 是《昨日重现》的精简/重构版本，位于独立远程仓库 `Robin-fang611/echoes-of-yesterday.git`。

### PROJECT_TREE.md 摘要

重建版采用多页面架构（非单 Canvas），包含以下页面：

| 页面 | 描述 |
|------|------|
| `main-menu.html` | 主菜单（5 按钮精灵图，UI v1.1 原版） |
| `game.html` | 游戏运行时容器（HTML 场景层 + Canvas 交互层） |
| `memory-report-artwork.html` | 章节记忆报告页（Artwork 版） |
| `memory-report.html` | 记忆报告页（旧版兼容） |
| `chapter-select.html` | 章节选择（10 章档案卡片） |
| `medical-notes.html` | 医学手记页（10 章医学知识） |

### 章节代码结构

重建版采用 `src/chXX/` 分目录组织每章代码：

| 章节 | 类型 | 文件 |
|------|------|------|
| Ch1 | 互动·镜前 | `ch01/Ch01Mirror.js` |
| Ch2 | 互动·接女儿 | `ch02/Ch02Puzzle.js` |
| Ch3 | 互动·迷途 | `ch03/Ch03Maze.js` |
| Ch4 | 互动·警局 | `ch04/Ch04Police.js` |
| Ch5 | 互动·归家 | `ch05/Ch05Door.js` |
| Ch6 | 纯漫画 | `ch06/Ch06Comic.js` |
| Ch7 | 互动·暗夜 | `ch07/Ch07Night.js` |
| Ch8 | 纯漫画 | `ch08/Ch08Comic.js` |
| Ch9 | 纯漫画 | `ch09/Ch09Comic.js` |
| Ch10 | 互动·认出 | `ch10/Ch10Report.js` |

### 交互模块

- `src/interactions/SignaturePuzzle.js` — Ch4 签字板
- `src/interactions/SmileDetector.js` — Ch8 微笑检测（摄像头）

## 与主仓（Echoes_of_Yesterday_New）的差异

| 维度 | 主仓 | 重建版 |
|------|------|--------|
| **提交数** | 51 | 30 |
| **包体** | 1.8GB | 230MB（压缩至 7.8MB） |
| **架构** | 单 Canvas（`index.html` + `src/main_new.js`） | 多页面（6 个 HTML 分页） |
| **远程** | Mrs-Zhang-0817/Echoes_of_Yesterday_New.git | Robin-fang611/echoes-of-yesterday.git |
| **漫画模式** | 嵌入 Canvas | 独立 `ComicChapter.js` 组件 |
| **UI 框架** | 纯 Canvas 绘制 | 含 UI v1.1 整套框架（UIManager/components/materials） |
| **医学手记** | 无 | 有（10 章医学知识图） |
| **构建** | `build.cjs` → `build_out/` | 未指定构建流程 |

### 包体优化

重建版提交 [5c6eaf8] 完成包体压缩：
- PNG → JPG（quality 25）
- 去重
- 结果：**170MB → 7.8MB**（压缩率 95%+）

### extract-ch1-3 分支

重建版有个 `extract-ch1-3` 本地分支，用途推测：
- 仅保留 Ch1-Ch3 的轻量版本
- 用于演示/展示场景（前 3 章互动物最密集）
- 与主分支形成"完整版 vs 精简演示版"并行结构
