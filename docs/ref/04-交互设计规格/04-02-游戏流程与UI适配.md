# 游戏流程与 UI 适配

## UI 提取结论

旧仓库 `Echoes_of_Yesterday` main（b8922d0）包含的两类重要 UI 在当前项目中的对应关系：

| 旧仓库模块 | 组成 | 当前项目对应位置 | 适配方式 |
|---|---|---|---|
| `MainMenuUI` | 菜单跳转事件 | 第一章开场与章节切换 | 保留 Canvas 状态机，不迁移页面跳转逻辑 |
| `MemoryReportScreen` | 纸张底图、照片框、三栏面板、日期章、清晰度、记忆列表、底部按钮 | 第十章报告页 | 作为 Canvas 报告页重绘规范 |
| `MemoryRestorationSequence` | 纸张唤醒、进度增长、图片/文字/印章依次出现 | 章节完成 Overlay 与第十章转场 | 转为 Canvas 时间轴动画 |
| `MemoryButton`、`Stamp`、`PhotoFrame`、`MemoryClarity` | 报告页原子组件 | `Overlay.js`、`ch10_report.js` | 提取视觉职责与交互语义，不直接复制 DOM 实现 |

## 旧 UI 层级顺序

`背景 → 固定纸张框 → 装饰 → 内容面板 → 标题 → 章节标题 → 底部交互`

当前游戏沿用这一层级，在单一 Canvas 内绘制；不直接引入旧仓库的 DOM/CSS 组件（避免两套输入、缩放与 16:9 定位系统）。

## 游戏总流程

玩家始终处于 **1280 x 720 横屏记忆画面**。每章由 `叙事开场 → 核心互动 → 完成反馈 → 章节结算` 构成。完成数据写入本地进度；第十章读取并呈现记忆恢复结果。

### 第 1 章：序曲·镜前

1. 画面进入卧室与镜前的旧照片氛围。
2. 玩家按引导完成镜面、衣物或广播相关的初始观察动作。
3. 叙事建立主人公记忆褪色、需要找回女儿线索的动机。
4. 完成后进入第 2 章，并记录最初的恢复进度。

### 第 2 章：接女儿放学·拼图

1. 玩家拖拽九宫格拼图碎片，将每块贴合到正确位置。
2. 放置正确时碎片吸附并产生短促反馈；错误位置不会锁定。
3. 拼图完成后，正式闪回图按时间淡入，表现校门、父亲与女儿。
4. 章节结算后记忆恢复至 15%。

### 第 3 章：迷途

1. 玩家从起点按连续路径描绘回家路线。
2. 路径触到错误节点会抖动并重置；松手后由规则校验是否到达终点。
3. 成功时播放城市上推的正式记忆帧，作为从迷路到看见目的地的反馈。
4. 章节结算后记忆恢复至 22%。

### 第 4 章：警局

1. 玩家在警局叙事中查看警员、电话和手环相关画面。
2. 通过既定的表单/签字互动完成确认动作。
3. 警局画面组用于承载叙事推进与关键物证提示。
4. 章节结算后记忆恢复至 30%。

### 第 5 章：归家迷途

1. 叙事结束后直接进入电梯面板。
2. 玩家阅读"有向日葵贴纸的那一层"的提示，辨认带正式向日葵贴纸的楼层按钮。
3. 点击错误楼层会给出错误反馈；点击正确按钮进入上行转场。
4. 旧版声源定位已按新版策划移除。章节结算后记忆恢复至 40%。

### 第 6 章：餐桌上的博弈

1. 画面展示家庭厨房与餐桌，中心是热面和荷包蛋。
2. 玩家抚摸碗壁，逐步提升安全感；触觉反馈与温暖光晕同步增长。
3. 安全感达到阈值后，料理与情绪状态完成转化。
4. 章节结算后记忆恢复至 52%。

### 第 7 章：惊悚夜醒

1. 玩家在夜间卧室叙事中进入黑暗探索。
2. 手指/鼠标移动形成局部手电光；玩家在画面中寻找门锁。
3. 靠近门锁时光晕与提示增强，点击门锁后暖光扩散、门被打开。
4. 设有超时兜底，避免用户无法继续。章节结算后记忆恢复至 60%。

### 第 8 章：自我和解

1. 玩家进入走廊、镜像与签字单的自我确认场景。
2. 在纸张上连续书写，系统保留笔迹的畸变规则与提交/清除动作。
3. 完成有效签名后，签字单成为自我和解的确认物。
4. 章节结算后记忆恢复至 72%。

### 第 9 章：风铃（两段式核心互动）

1. 阳台开场：玩家把四个彩色音符（Do/Re/Mi/Fa）拖回五线谱上对应颜色的槽位，拼回记忆的风铃。
2. 闪回：回看"父亲做风铃"的叙事帧（由 FlashbackActivity 驱动的叙事活动，表现形式可整体替换）。
3. 音游：四根彩色风铃管对应下落音符，到判定线时点击对应管；命中累积 Combo、客厅由冷转暖；连续漏击自动慢速以防卡关。
4. 章节结算后记忆恢复至 85%。

### 第 10 章：认出·不迷路（终局闭合 100%）

1. 玩家看到晨光客厅与一碗热粥，并点击粥碗。
2. 蒙太奇（由 MontageActivity 驱动的叙事活动，表现形式可整体替换）按帧柔和淡入回看这一路：客厅 → 粥 → 女儿特写 → 父女拥抱，并配字幕。
3. 父女拥抱定格（白场过渡），再进入记忆恢复报告；报告按旧 UI 层级展示档案背景、章节/日期、照片、已恢复与未恢复内容、清晰度、情感文字、印章与操作按钮。
4. **进入报告时显式写档 `markChapterComplete(10,100)`**，记忆进度正确达到 100%、第十章已勾选。
5. "重新开始"清空本地进度并回到第 1 章。

## 验收标准

1. 所有 UI 均在 16:9、手机横屏与桌面等比缩放下保持可读、可点。
2. Canvas 内只有一套输入处理；Overlay 出现时必须独占输入。
3. 报告页的文字、照片和按钮不得超出画布或与章节交互热区重叠。
4. 每个 UI 改造均需通过构建、资源加载检查和真实浏览器截图验证。
